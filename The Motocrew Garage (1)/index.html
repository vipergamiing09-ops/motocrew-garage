To enable Google login, you need to set up a Google OAuth Client ID. See instructions below.

Setup Google Login (One-Time)

  1. Go to Google Cloud Console
  2. Create a new project (or select existing)
  3. Go to APIs & Services > OAuth consent screen > Configure
  4. Go to APIs & Services > Credentials > Create OAuth Client ID (Web application)
  5. Add your website URL to "Authorized JavaScript origins"
  6. Copy the Client ID and paste it into app.js where it says YOUR_GOOGLE_CLIENT_ID
